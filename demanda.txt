Realizar o levantamento, classificação e catalogação dos tipos e categorias de recursos existentes nos ambientes de Cloud Computing utilizados pela organização, contemplando os provedores Microsoft Azure, Amazon Web Services (AWS), Google Cloud Platform (GCP), IBM Cloud e Azure Red Hat OpenShift (ARO).
 
O objetivo desta iniciativa é identificar e estruturar, de forma padronizada, todos os recursos passíveis de monitoramento, estabelecendo uma visão consolidada por provedor e uma visão detalhada por categoria de serviço.
 
O levantamento deverá considerar dois níveis de análise:
 
1. Visão Macro (Categorias/Tipos de Recursos)
Identificação das principais categorias de serviços e recursos disponíveis em cada Cloud Provider.
Agrupamento dos recursos por domínio tecnológico, como Computação, Rede, Armazenamento, Banco de Dados, Containers, Segurança, Integração, Observabilidade, entre outros.
2. Visão Micro (Recurso Unitário)
Detalhamento individual de cada recurso pertencente às categorias identificadas.
Definição das características relevantes para monitoramento, tais como métricas, eventos, logs, disponibilidade, desempenho, consumo e dependências.
Embora o Azure Red Hat OpenShift (ARO) seja executado sobre infraestruturas de Cloud Providers, ele deverá ser tratado como uma categoria independente neste levantamento, devido ao seu alto nível de abstração e encapsulamento tecnológico fornecido pela Red Hat, demandando uma abordagem específica para identificação e monitoramento de seus componentes e serviços.
Como resultado esperado, deverá ser produzida uma matriz/inventário contendo:
Cloud Provider;
Categoria/Tipo de recurso;
Recurso específico;
Descrição funcional;
Requisitos e capacidades de monitoramento;
Métricas, logs e eventos relevantes;
Criticidade e observações.
Este levantamento servirá como base para a definição da estratégia corporativa de observabilidade e monitoramento multicloud, garantindo padronização, cobertura adequada dos recursos e melhor governança operacional dos ambientes.
